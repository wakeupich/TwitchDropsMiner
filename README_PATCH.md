3. **Обработка сессий:**
   * Добавлена поддержка сохранения и восстановления сессионных токенов `auth-token` для клиента `SMARTBOX`.

1. Запустить `Twitch Drops Miner (by DevilXD).exe`.

3. Программа отобразит 8-значный код и откроет страницу [twitch.tv/activate](https://www.twitch.tv/activate).
